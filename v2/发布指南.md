# 西瓜todo v2 自动打包发布指南

代码已跨平台适配（Windows / macOS），并配置了 GitHub Actions，
**提交代码后可自动生成 Win 和 Mac 安装包并挂到 GitHub 下载页。**

## 一、只需做一次的准备

1. 把 `watermelon-todo` 目录推送到你的 GitHub 仓库（工作流文件在
   `.github/workflows/build-release-v2.yml`，会随代码一起上传）。
2. 打开仓库 **Settings → Actions → General**，在 “Workflow permissions”
   选择 **Read and write permissions** 并保存（否则无法自动创建 Release）。

## 二、日常发布：推一个版本 tag 即可

改完代码后，在本地执行（版本号与 `todo_qt_v2.py` 里的 `APP_VERSION` 保持一致）：

```bash
git add .
git commit -m "更新内容说明"
git push

# 打一个以 v 开头的 tag 并推送，即触发自动打包
git tag v3.0
git push origin v3.0
```

推送 tag 后，GitHub 会自动：

- 在 **Windows** 机器上打包 → `西瓜todo.exe`（便携版）+ `西瓜todo-2.0-Setup.exe`（安装版）
- 在 **Mac** 机器上打包 → `西瓜todo-2.0-mac.dmg`
- 自动创建 **Releases 下载页**，把三个安装包挂上去

在仓库首页右侧 **Releases** 即可看到下载页，把链接发给别人就能直接下载。

> 想发新版本时，改大 tag 号即可，例如 `git tag v2.1 && git push origin v2.1`。

## 三、只想测试打包、先不发布

进入仓库 **Actions** 页 → 选择 “打包并发布西瓜todo v2” →
点 **Run workflow**。这样只会打包，产物在该次运行的 **Artifacts** 里下载，
不会创建正式 Release。

## 四、产物说明

| 文件 | 平台 | 用法 |
|------|------|------|
| `西瓜todo-<版本>-Setup.exe` | Windows | 双击安装，自动建桌面快捷方式 |
| `西瓜todo.exe` | Windows | 免安装，双击即用 |
| `西瓜todo-<版本>-mac.dmg` | macOS | 双击后把图标拖进「应用程序」 |

> Mac 首次打开若提示“无法验证开发者”，到
> **系统设置 → 隐私与安全性** 点“仍要打开”即可（因为未做 Apple 付费签名/公证）。

## 五、说明

- 打包由 GitHub 云端的 Windows / Mac 机器完成，你本地无需安装任何环境。
- 图标由 `watermelon_logo.svg` 在打包时自动生成 `.ico` / `.icns`。
- 旧的 `build-release.yml` 已停用（改为仅手动触发），避免与 v2 工作流重复。
